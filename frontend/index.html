Workflow 4 bước

  1. Chọn một hoặc nhiều file PDF bằng nút “Chọn file trên máy”.
  2. Chọn nơi lưu: cùng thư mục file gốc, thư mục khác, hoặc ghi đè file gốc có backup.
  3. Chọn loại tài liệu Toán/Lý/Hóa/Ebook và preset tốc độ/chất lượng.
  4. Bấm “Xử lý PDF”, theo dõi tiến trình và log.

Tối ưu tốc độ

  • Mặc định đã bật PNG compression = 0 cho output PNG lossless: nhanh hơn nhưng file có thể lớn hơn.
  • QC mặc định kiểm tra đầy đủ theo từng trang; chế độ nhanh chỉ lấy mẫu các trang đại diện.
  • QC nhanh và Tắt QC chỉ nên dùng khi bạn đã tin nguồn PDF/mode đang dùng.

Lưu ý kỹ thuật

  • Giao diện gọi Python trực tiếp qua cầu nối native của pywebview, không dùng FastAPI hay cổng mạng.
  • Ứng dụng xử lý trực tiếp file thật trên máy qua cửa sổ desktop native.
  • Graph-safe luôn được bật cho Toán/TDM.
  • Aggressive mode chỉ dành cho Lý/IPCLASS.
  • QC mặc định cảnh báo khi thấy mất nội dung trực quan; lỗi cấu trúc nghiêm trọng vẫn chặn output.
